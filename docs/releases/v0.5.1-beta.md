# Steam Advanced Collections v0.5.1-beta

The first public beta adds advanced rules to Steam's existing dynamic collections through Millennium. It uses Steam's own editor and cover grid; static collections are untouched.

## Highlights

- Nested AND / OR / NOT groups, individual exclusions and group inversion.
- Steam tags and features, personal/Steam Families ownership, local installation status and Steam library folders.
- Playtime, Last Played, Install Size and Release Date comparisons and ranges.
- Developer, Publisher, Steam Reviews, Achievement Progress and Languages (Interface, Subtitles and Full Audio).
- Live preview in the native cover grid, with an approximately 250 ms debounce once required metadata is available.
- Verified per-account, per-collection rule persistence and automatic restoration after restarting Steam.
- Save/Cancel and draft cleanup on closing or changing editors. Drafts stay in memory only.
- Native filters remain combined with advanced rules using AND; Steam's manual additions and exclusions keep their priority.

## Achievement Progress fix

The validated 0.5.1 fix is included. When Steam's aggregate achievement cache is unavailable, the plugin loads personal achievement data through the same native API used by Steam's achievement page. Successful responses trigger a targeted recalculation. Requests are shared, cached and rate-limited.

A game displayed at 31% matches Greater than 20%, Between 20% and 40%, and NOT Greater than 50%; it does not match Greater than 50%. Comparisons use the unrounded fraction. Zero progress, completion, no achievements and unknown data remain distinct. NOT of unknown stays unknown.

## Install

1. Install Millennium and fully exit Steam.
2. Download **`com.steamadvancedcollections.plugin.star`** from this release's Assets. Do not use the source-code ZIP as the plugin.
3. Copy the archive, without extracting it, into your Steam installation's **`millennium/plugins`** folder. Replace only the existing archive of that name when upgrading.
4. Start Steam and enable **Steam Advanced Collections** in **Steam → Millennium → Plugins**. Restart Steam if requested.
5. Edit a dynamic collection using its gear icon, enable advanced rules in **Advanced Filters**, and add conditions.

`SHA256SUMS.txt` contains the archive's SHA-256 checksum. The archive is unsigned and may be shown as untrusted by Millennium. Sources and automated tests remain in the repository.

## Compatibility and limitations

- Tested manually on Windows desktop Steam with **Millennium 3.6.2**, including the Achievement Progress fix. Linux, Steam Deck and Big Picture are not validated. Interface language: English.
- This is a **pre-release**. Integration relies on internal Steam interfaces and may need maintenance after Steam or Millennium updates. Other plugins can also affect compatibility. Missing integration falls back to native Steam behavior.
- The first preview may wait for asynchronous metadata; broad filters can take longer to resolve. Offline, stale or missing data remains unknown rather than becoming zero. The native result is retained while the expression is unknown; with no native filters, that can mean an empty collection until data arrives.
- Ownership reflects Steam license/family signals, not proof of purchase. Remote Play-only installs are not local installs; disconnected libraries and unavailable size data remain unknown.
- Developer/publisher matching uses exact names, case-insensitively. Language modes depend on Steam's distinct flags and the 32 verified client language IDs. Achievement percentages can differ from Steam's truncated display.
- Existing Steam Category and legacy Installation Drive rules remain supported. New location conditions use Steam library folders. No saved rules are automatically rewritten.
- No direct Steam internal configuration edits or static collection changes. Advanced rules remain saved when the plugin is disabled.
- GitHub distribution only; no SteamBrew catalog submission. Screenshots are planned but are not included yet.

## Validation and feedback

125 automated tests pass, including persistence, native preview, Save/Cancel, unknown-value logic and the 31% achievement regression. TypeScript, compilation and package verification pass. The underlying 0.5.1 behavior has also been validated manually by the maintainer in Steam.
